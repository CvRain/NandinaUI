# 使用布局系统组织界面

当窗口中只有一个控件时，位置似乎不是问题；一旦标题、说明文字和按钮同时出现，界面就需要一套稳定的空间规则。NandinaUI 的布局系统通过 `Row`、`Column`、`Center`、`Padding`、`Expanded` 等容器表达父子关系和尺寸约束，让界面结构本身就能说明各个控件应当如何排列。

本章会把前面的文本和按钮组合成一个小型界面，并借此认识“约束向下传递、尺寸向上返回、位置由父级安排”的布局思路。目标不是穷举所有容器，而是让开发者能够选择正确的基础布局、理解固定尺寸与自适应尺寸的区别，并写出易于继续扩展的控件树。

## 本章目标

- 使用 `ui.row()`、`ui.column()`、`ui.center()` 和 `ui.padding()` 组合控件。
- 使用 `.child()` 与 `.children()` 建立清晰的父子结构。
- 配置间距、主轴方向与交叉轴对齐。
- 理解内容尺寸、填充尺寸、百分比尺寸以及最小/最大约束。
- 知道何时使用 `Expanded`、`FlexItem`、`Grid`、`Stack` 或 `ScrollView`。

## 建议覆盖的知识点

- `NanControl` 的测量与布局过程。
- `Row` / `Column` 与通用 `Flex` 的关系。
- `gap`、`LayoutAlignment`、padding 和嵌套容器。
- `.width()`、`.height()`、`fill`、`content`、`percent` 等尺寸表达。
- 控件树可读性：优先表达结构，再处理局部视觉配置。

> 建议以“标题 + 说明 + 操作区”为本章最终界面，并用窗口缩放检查布局是否仍然合理。
