# NandinaUI 入门指南

这组文档通过一个逐步完善的小型桌面应用，介绍 NandinaUI 最常用的开发路径。每一章只增加一个核心概念，并延续上一章的代码，使读者能够在较短时间内建立从应用入口到页面导航的整体认识。

## 学习路线

1. [认识 NandinaUI](1_overview.md)：项目定位、架构、环境与工程接入。
2. [创建第一个窗口](2_first_window.md)：应用入口、窗口配置与根视图。
3. [添加一个按钮](3_button_interaction.md)：控件创建、外观配置与点击回调。
4. [使用布局系统组织界面](4_layout_system.md)：控件树、尺寸约束与常用容器。
5. [用信号驱动界面更新](5_signal_system.md)：Signal、Computed、Effect 与绑定。
6. [使用 app::Page 组织应用](6_page_and_navigation.md)：页面、参数、生命周期与路由。

## 完成后你将理解

- NandinaUI 应用从启动到绘制界面的基本链路。
- 如何使用声明式构建器组合和配置内置控件。
- 如何通过响应式状态让数据变化自动反映到界面。
- 何时使用简单根视图，何时引入 `app::Page` 与路由。

这套入门指南刻意不深入主题定制、资源系统、动画、异步任务和应用级 Store。它们更适合作为完成基础路线后的独立专题。
