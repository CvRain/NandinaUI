# Getting Started 章节模板

> **这是模板，不是文档。** 新增章节时复制本结构，删掉本提示行。
>
> 现有章节（`4_layout_system.md` / `5_signal_system.md` / `6_page_and_navigation.md`）已经是这个
> 形态：标题 + 导语 + 本章目标 + 建议覆盖的知识点。本模板把那套结构固定下来，并补齐一篇文章
> 通常需要的其余部分。

## 分工与写法

- 框架（标题层级、清单、占位符）由 AI 提供；**正文全部手写**。
- 每章应当**可运行**：读者跟着做完，能得到一个能跑的东西。不要只讲概念。
- 章与章之间要有承接：开头一句回指上一章，结尾一句指向下一章。
- 术语首次出现时给定义；后续章节不要重复定义，用链接回指。

## 核对清单（提交前自查）

- [ ] 本章代码示例**可编译、可运行**（不是伪代码）
- [ ] 示例只使用 recommended API
- [ ] 与前一章的产物衔接（读者手里已经有上一章的结果）
- [ ] 结尾指向下一章（或明确说明这是最后一章）
- [ ] 新增术语已定义
- [ ] 更新 `docs/getting_started/README.md` 的章节导航
