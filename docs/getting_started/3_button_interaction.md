# 添加一个按钮

静态界面只是起点，用户能够与界面发生交互之后，应用才真正开始工作。本章会在第一个窗口中加入 `widget::Button`，并通过点击回调执行一段简单逻辑。借助 `BuildContext` 提供的构建器，一个按钮可以在创建时同时完成文本、外观与行为配置，而不需要把界面声明拆散到多个位置。

按钮也是理解 NandinaUI 控件模型的理想入口：它既是控件树中的节点，也拥有主题定义的视觉状态和输入语义。本章只关注应用层最常用的创建与点击处理方式，更深入的样式、焦点、键盘操作和无障碍语义可以留到组件专题中展开。

## 本章目标

- 使用 `ui.make<widget::Button>()` 创建按钮。
- 通过 `.on_click()` 注册点击回调。
- 使用 `.tone()`、`.treatment()` 等构建器方法调整基础外观。
- 理解构建器、实际控件对象与 `.build()` 返回值之间的关系。
- 了解回调生命周期为何由当前构建作用域保护。

## 建议覆盖的知识点

- `widget::Button` 与底层 `Pressable` 的关系。
- 声明式构建器和直接调用 `set_on_click()` 两种写法的取舍。
- `ButtonTone`、`ButtonTreatment`、`ButtonSize` 的基本用途。
- `.configure()` 与 `.expose()` 适合解决的问题。
- 点击回调中捕获局部状态时需要注意的生命周期边界。

> 建议让本章的按钮先产生一个可观察但简单的结果，例如输出日志；状态驱动的文本更新留到第五章完成。
