# Guide：按主题深入

Getting Started 带你跑通第一个界面；本目录解决**入门之后**的问题 —— 按主题讲清"用这套框架
做好一类事情"的方法。

## 与其他目录的分工

| 目录 | 面向 | 阅读时机 |
| --- | --- | --- |
| [`getting_started/`](../getting_started/README.md) | 初次使用者 | 第一次接触本项目 |
| **`guide/`**（本目录） | 使用者 | 已经能跑起来，要系统掌握某类能力 |
| [`components/`](../components/README.md) | 使用者 | 查某个组件怎么用 |
| [`references/`](../references/README.md) | **框架开发者** | 改框架本身、理解架构决策 |

> `references/` 是开发手册（记录架构决策与迁移），不是使用者的学习材料。

## 建议的篇目

> 本节只是选题清单，篇目是否编写、以什么顺序编写由维护者决定。
> 每篇请复制 [`_template.md`](_template.md)。

| 篇目 | 讲什么 | 状态 |
| --- | --- | --- |
| 布局与约束 | 约束向下、尺寸向上、位置由父级安排；何时用哪种容器 | 待写 |
| 响应式状态 | Signal / Computed / Effect 的使用视角；状态该放在哪一层 | 待写 |
| 页面与导航 | 应用结构、页面参数、路由栈与生命周期 | 待写 |
| 主题与样式 | 语义角色怎么选、配方与实例覆盖的优先级 | 待写 |
| 浮层与反馈 | 浮层层级、关闭语义、嵌套关系、何时用哪个组件 | 待写 |
| 键盘与无障碍 | 焦点模型、roving focus、语义属性要怎么填 | 待写 |
| 自定义组件 | 在本仓库新增组件的完整流程 | 待写 |
| 文本与国际化 | 字体、换行、RTL 与双向文本 | 待写 |
| 性能与渲染 | 绘制、缓存、动画与重绘的边界 | 待写 |

## 写作约定

- 按**读者要达成的事**命名篇目，不要按框架内部模块命名；
- 示例必须可编译；只使用 recommended API；
- 必写「什么时候不要这样做」一节；
- 需要解释框架内部时，链接到 `references/`，不要在本目录重复架构说明。
