# 组件文档模板

> **这是模板，不是文档。** 新增组件文档时复制本文件的结构，删掉本提示行。
>
> 分工约定：框架（标题层级、表格、待填清单）由 AI 提供；**正文全部手写**。AI 可以帮你核对
> 符号名与默认值，但不要让它代写叙述性内容 —— 这是本项目"代码 AI 写、文档人写"的分工。

## 使用说明

- 占位符统一写作 `<!-- TODO: … -->`，便于全局检索未完成项：`grep -rn "TODO" docs/`
- 表格中列出的 **API 名称与默认值应与代码一致**，写完请用下面的核对清单过一遍。
- 「已知空白」一节必须写实：没有就说没有，不要为了完整而编造。

## 核对清单（提交前自查）

- [ ] 所有符号名（类、方法、构造器、枚举）与当前代码一致
- [ ] 代码示例**可编译**（至少手动编译过一次，而不是凭印象写）
- [ ] 默认值（尺寸、间距、圆角、状态）与 `default_*_recipe()` 一致
- [ ] 键盘行为与 `on_input()` 实际实现一致
- [ ] 语义（role / label / state / action）与 `semantics_properties()` 一致
- [ ] 已链接到 `docs/components/README.md` 的索引表
- [ ] 「已知空白」如实填写
